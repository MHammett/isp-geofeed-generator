# Prior art and reuse decisions

Initial review on 2026-11-15; dated additions are linked below. These are source and documentation reviews, not live tests of
the listed projects. No third-party implementation has been copied into this repository.

## Closest geofeed generators

The 2026-11-16 NANOG announcement adds [Geoflaw diagnostic prior art](geoflaw.md).
It covers registry discovery and retrieval/coverage findings beyond local syntax checks.
Its dated snapshot is not live provider acceptance or a required publication gate.

| Project | What it does | License checked | Useful next step |
| --- | --- | --- | --- |
| [GeoBox](https://github.com/FrumentumNL/GeoBox/tree/834b4f7856cf53a70f05ad66b2ba4ec397f21ec5) | Reads NetBox prefixes. Uses prefix custom fields for location, inheritance by omitted rows, and explicit blank-location rows. | MIT | Consider an optional prefix-field input mode and a migration guide for existing users. |
| [NetBox RFC8805 Prefix Generator](https://github.com/rarsenault/netbox-rfc8805-prefix-generator/tree/48d34e52748a02a2b846c24f43db9c82a957c948) | Uses Region-scoped prefixes and a country/state/city hierarchy. Supports exclusions and same-location aggregation. | No license file found in the reviewed root; GitHub reported no license. | Use as a behavior reference. Do not copy code without a license grant. Consider a Region-scope mode with strict completeness checks. |
| [Turtlebit geofeeds](https://github.com/Turtlebit/geofeeds) | Operator feed repository with a generator and geographic YAML input. | Not established in this review | Example of reviewed file input and static hosting. No code reuse decision. |

GeoBox's CLI takes the API token as an argument. Its source also follows API-supplied
pagination links. Reuse of its location model does not mean adopting those credential or
transport choices. Keep our protected credential references and bounded same-endpoint reads.

The Region-based exporter warns about unresolved locations and can still exit successfully.
Our scheduled publisher must retain its failure behavior for missing selected records.
Region and prefix-field modes are adapter gaps here. NetBox itself supports those models.

## ISP API integration examples

[LibreQoS](https://github.com/LibreQoE/LibreQoS/tree/9ebe29bc9d49013aff9b0544de3c6f6fc6ba2f1d)
has useful VISP, Powercode, UISP, Sonar and Splynx integrations. The reviewed repository
reports GPL-2.0. Do not copy its implementation into this MIT project without a compatible
licensing plan. API operation names can guide checks against vendor contracts.

Its VISP importer uses equipment-to-site/upstream relationships when IRM data exists.
Its UISP model separates infrastructure sites and subscriber endpoints. Its Powercode
importer reads subscriber shaping data. Those paths do not establish whole-pool hosting.
The Powercode example disables certificate checks; that behavior must not be adopted.

[Ubiquiti's UCRM plugin repository](https://github.com/Ubiquiti-App/UCRM-plugins) supplies
MIT examples for CRM plugins. CRM integration is separate from UISP Network IPAM discovery.

## Independent validators

| Project | License checked | Intended use |
| --- | --- | --- |
| [MaxMind mm-geofeed-verifier](https://github.com/maxmind/mm-geofeed-verifier/tree/v5.0.0) | MIT or Apache-2.0 | External format check; optional database comparison. |
| [Massimo Candela geofeed-validator](https://github.com/massimocandela/geofeed-validator/tree/ede8916ee1045fa806554bb76112d0fecc63b40d) | BSD-3-Clause | Executed on 2026-11-16: detects invalid prefixes and ISO codes in the shared controls. Does not check whole-feed duplicate/overlap policy in this experiment. |
| [Anexia geofeed-validator](https://github.com/anexia-it/geofeed-validator/tree/c376a09d1ae20a783ee5cd923f209b5ded606fc0) | AGPL-3.0 | Candidate standalone check. Review license obligations before incorporating it. Not executed. |
| [Fastah IP geofeed skills](https://github.com/fastah/ip-geofeed-skills) | Apache-2.0, as reported by its repository | Operator review workflow. No platform inventory adapter or publication claimed here. Not executed. |

The MaxMind v5.0.0 Windows AMD64 artifact matched the vendor checksum manifest:
`1386b215ea83bce03bd2cf0d69b5d232ef477a473bb077755339756c378ddf7a`.
It accepted an 11-row synthetic feed generated by this project and rejected an invalid
IP prefix. It also accepted the invalid-country control `XX` paired with region `US-IL`.
The combined experiment therefore failed its expected negative controls. Do not describe
that pass as country-code or geographic verification. No MMDB comparison was run.
Read-only diagnosis of the pinned source found that its format-only branch checks the IP
prefix and a region formatting rule, then returns before database-backed comparison.
The later [conformance comparison](conformance.md) reran both pinned tools on 13 controls,
including CRLF, Unicode, IPv6, code membership and whole-feed/publisher policies.

Before adopting a validator, pin a revision, run good and deliberately bad fixtures,
and document which faults it detects. A format check cannot prove allocation ownership,
customer geography or a pool-to-facility relationship.

## Search coverage

Searched public web results, GitHub repository search and GitHub code search for geofeed
with Sonar, NetBox, Splynx, Powercode, VISP, UISP, Nucleo and Vision/Fibersmith.
The platform-specific GitHub code queries returned no matches for Sonar, Splynx,
Powercode, VISP, UISP or Nucleo. Search is not exhaustive and private projects were not searched.
No general multi-platform pool-to-facility geofeed generator was verified in that search.
Existing operator CSV repositories and feed aggregators are not evidence of billing adapters.
