# ISP Geofeed Generator

An independent, open-source tool for generating and safely publishing ISP geofeeds from billing and IPAM platforms.

Initial implementation is being prepared in a pull request. Sonar and NetBox are the first sources.
Other adapters will be labeled clearly as initial support until operators verify them on real instances.

Platform capability, operator configuration, and adapter verification are tracked separately.
Credentials and private network inventory must never be posted in issues or pull requests.

This repository is not affiliated with the platform vendors.
